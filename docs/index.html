Livestock Health Ontology

A shared structure and meaning for animal health data of cattle, pigs, poultry and salmon across laboratories and countries.

Ontology file on GitHub AgroPortal BioPortal How to use it Try a query

Overview

The Livestock Health Ontology (LHO) gives animal health data from different laboratories, countries and species a shared structure and meaning. It was developed in the EU Horizon 2020 project DECIDE (grant agreement 101000494) for diagnostic data on cattle, pigs, poultry and salmon. A laboratory converts its own columns and codes to LHO terms once; after that, the same query or model works on the data of every laboratory.

Terms are linked to AGROVOC, NCIT, AHOL and the NCBI Taxonomy where a matching term exists.

Where to get it

  • Ontology file and source: GitHub, decide-project-eu/LivestockHealthOntology
  • Browse the terms: AgroPortal and BioPortal
  • Address of the ontology: http://www.purl.org/decide/LiveStockHealthOnto/LHO. Each term has its own address under it. Some terms are addressed by name, for example LHO#BRSV; others by a code, for example LHO#CS07 for PCR. The name of a coded term is in its label.

How to use it

Ask the ontology which terms exist

These queries need only the ontology file.

1. Pathogens of cattle. Returns the pathogens that the ontology defines for cattle, with their description. Every laboratory that runs this query on the same file gets the same list.

SELECT ?pathogen ?description WHERE {
  ?pathogen a decide:Pathogen ;
            LHO:affectsSpecies LHO:Cattle .
  OPTIONAL { ?pathogen rdfs:comment ?description }
}
ORDER BY ?pathogen

Run this query

2. Pathogens, species and the disease they cause. For every pathogen: the species it affects and the kind of disease it causes. The name of the pathogen is shown where the ontology has one, otherwise its short code.

SELECT ?species ?pathogen ?disease WHERE {
  ?p a decide:Pathogen ;
     LHO:affectsSpecies ?s ;
     LHO:causesDisease ?d .
  ?d rdfs:label ?disease .
  OPTIONAL { ?p rdfs:label ?name }
  BIND (COALESCE(STR(?name), STRAFTER(STR(?p), "#")) AS ?pathogen)
  BIND (STRAFTER(STR(?s), "#") AS ?species)
}
ORDER BY ?species ?pathogen

Run this query

3. Terms with a Dutch name. Terms that have a Dutch name. Change nl to fr, de, es or ar for another language.

SELECT ?term ?dutch WHERE {
  ?t skos:altLabel ?dutch .
  FILTER (lang(?dutch) = "nl")
  FILTER (CONTAINS(STR(?t), "purl.org/decide") && CONTAINS(STR(?t), "#"))
  OPTIONAL { ?t rdfs:label ?name }
  BIND (COALESCE(STR(?name), STRAFTER(STR(?t), "#")) AS ?term)
}
ORDER BY ?term
LIMIT 30

Query sample records

A laboratory writes each test result as a sample that points to terms of the ontology. The laboratory data of DECIDE are not public, so the queries below run on a few invented samples that are part of this page: ten of cattle, six of pigs, six of poultry, and two poultry farms. Result 1 is a positive test.

4. Cattle samples: positive for Mycoplasma bovis in swabs. Cattle samples with pathogen MB, sample type Swab and result 1 (positive). This is the cattle query of the data access paper (reference 3).

SELECT ?Sample ?Pathogen ?Breed ?SampleType ?DiagnosticTest ?Country ?Province ?SampleResult
WHERE {
  ?Sample a LHO:CattleSample ;
          LHO:hasPathogen ?Pathogen ;
          LHO:hasSampleType ?SampleType ;
          LHO:hasCountry ?Country ;
          LHO:hasProvince ?Province ;
          LHO:hasBreed ?Breed ;
          LHO:hasDiagnosticTest ?DiagnosticTest ;
          LHO:hasResult ?SampleResult .
  FILTER(?Pathogen = LHO:MB)
  FILTER(?SampleType = LHO:Swab)
  FILTER(?SampleResult = LHO:1)
}

Run this query

5. Pig samples: positive for Mycoplasma hyopneumoniae in finishing pigs. Pig samples of tissue from the finishing stage with result 1 for Mycoplasma hyopneumoniae. Pigs have one extra property, the production stage.

SELECT ?Sample ?Pathogen ?Breed ?SampleType ?DiagnosticTest ?ProductionStage ?Country ?SampleResult
WHERE {
  ?Sample a LHO:PigSample ;
          LHO:hasPathogen ?Pathogen ;
          LHO:hasCountry ?Country ;
          LHO:hasResult ?SampleResult ;
          LHO:hasBreed ?Breed ;
          LHO:hasSampleType ?SampleType ;
          LHO:hasDiagnosticTest ?DiagnosticTest ;
          LHO:hasProductionStages ?ProductionStage .
  FILTER(?Pathogen = LHO:Mycoplasmahyopneumoniae)
  FILTER(?SampleType = LHO:Tissue)
  FILTER(?ProductionStage = LHO:Finishing)
  FILTER(?SampleResult = LHO:1)
}

  FILTER(?SampleType = LHO:SS)
  FILTER(?ProductionStage = LHO:Broiler)

7. Cattle, pig and poultry in one query. The three queries above joined with UNION, as in the data access paper. One query returns samples of three species, because all three are described with the same terms.

SELECT ?Sample ?Species ?Pathogen ?Breed ?SampleType ?DiagnosticTest ?ProductionStages ?Country ?SampleResult
WHERE {
  {
    ?Sample a LHO:CattleSample ;
            LHO:hasPathogen ?Pathogen ; LHO:hasCountry ?Country ; LHO:hasResult ?SampleResult ;
            LHO:hasBreed ?Breed ; LHO:hasSampleType ?SampleType ; LHO:hasDiagnosticTest ?DiagnosticTest .
    FILTER(?Pathogen = LHO:MB) FILTER(?SampleType = LHO:Swab) FILTER(?SampleResult = LHO:1)
    BIND("NA" AS ?ProductionStages) BIND("Cattle" AS ?Species)
  }
  UNION
  {
    ?Sample a LHO:PigSample ;
            LHO:hasPathogen ?Pathogen ; LHO:hasCountry ?Country ; LHO:hasResult ?SampleResult ;
            LHO:hasBreed ?Breed ; LHO:hasSampleType ?SampleType ; LHO:hasDiagnosticTest ?DiagnosticTest ;
            LHO:hasProductionStages ?Stage .
    FILTER(?Pathogen = LHO:Mycoplasmahyopneumoniae) FILTER(?SampleType = LHO:Tissue)
    FILTER(?Stage = LHO:Finishing) FILTER(?SampleResult = LHO:1)
    BIND(?Stage AS ?ProductionStages) BIND("Pig" AS ?Species)
  }
  UNION
  {
    ?Sample a LHO:PoultrySample ;
            LHO:hasPathogen ?Pathogen ; LHO:hasBreed ?Breed ; LHO:hasSampleType ?SampleType ;
            LHO:hasProductionStages ?Stage ; LHO:hasCountry ?Country ; LHO:hasResult ?SampleResult .
    FILTER(?Pathogen = LHO:QX) FILTER(?SampleType = LHO:SS)
    FILTER(?Stage = LHO:Broiler) FILTER(?SampleResult = LHO:1)
    BIND(?Stage AS ?ProductionStages) BIND("Poultry" AS ?Species) BIND("NA" AS ?DiagnosticTest)
  }
}
ORDER BY ?Species ?Sample

Run this query

8. Poultry records: farm, house, flock and their values. Follows the links from a poultry farm to its houses and flocks, and returns the values recorded for each flock.

SELECT ?farm ?houseNumber ?flock ?hatchDate ?removalDate ?growthCurve WHERE {
  ?pf LHO:CS29 ?house .              # hasHouse
  ?house LHO:CS45 ?houseNumber ;      # houseNumber
         LHO:CS30 ?f .                # hasFlock
  ?f LHO:CS32 ?flock ;                # hasFlockID
     LHO:CS34 ?hatchDate ;            # hasHatchDate
     LHO:CS35 ?removalDate ;          # hasRemovalDate
     LHO:CS36 ?growthCurve .          # hasGrowthCurve
  FILTER (STRSTARTS(STR(?pf), "https://example.org/"))
  BIND (STRAFTER(STR(?pf), "poultryfarm-") AS ?farm)
}
ORDER BY ?farm ?houseNumber

Inference

The ontology contains two rules from which new links follow. A query engine does not apply such rules itself; a reasoner does. For this page the links were derived once with an OWL RL reasoner (owlrl in Python) and stored in the page, so the two queries below can find them.

9. Inference: the flocks of each farm. No record says which flock belongs to which farm. The ontology defines hasAssociatedFlock as a chain of three links: farm to poultry farm, poultry farm to house, house to flock. A reasoner follows the chain and adds the link from farm to flock.

SELECT ?farm ?flock WHERE {
  ?fa LHO:CS38 ?f .                   # hasAssociatedFlock
  ?f LHO:CS32 ?flock .                # hasFlockID
  BIND (STRAFTER(STR(?fa), "farm-") AS ?farm)
}
ORDER BY ?farm ?flock

Run this query

10. Inference: neighbouring countries in both directions. The file states that Belgium has France and the Netherlands as neighbours. hasGeographicNeighbor is a symmetric property, so a reasoner adds the two links in the other direction.

SELECT ?country ?neighbour WHERE {
  ?country LHO:hasGeographicNeighbor ?neighbour .
}
ORDER BY ?country

Description

  • LHO integrates domain knowledge and data for livestock health. The ontology covers farms, samples, geolocation, breed, diagnostic tests, and pathogen identification, including bacteria like Histophilus somni, Mannheimia haemolytica, Pasteurella multocida, Bovine coronavirus, bacterial mycoplasma, and aerobic culture results in cattle. For pigs, it includes FarmType, age, weight, and pathogens like PRRS, SI and M_Hyponemoniea. In poultry, LHO incorporates FarmType, with specific pathogen names such as Infectious Bronchitis (IB), providing a concise overview of health aspects across livestock species.

LivestockHealthOntology c

IRI http://www.purl.org/decide/LiveStockHealthOnto/LHO#LivestockHealthOntology
Description

The Live Stock Health Ontology (LHO), an extension of the DECIDE ontology, serves as a structured framework for organizing information related to the health and well-being of livestock species, encompassing cattle, poultry, pig, and salmon.

LHO facilitates the integration of domain knowledge and data, offering explicit representations of various aspects. In the development process, insights from domain experts contribute to the creation of a prototype designed for reasoning and planning of data, particularly concerning cattle.

Within LHO, concepts include farms with identifications, samples, geolocation, breed, diagnostic tests, and pathogen identifications. Notably, specific bacteria like Histophilus somni (HS), Mannheimia haemolytica (MH), Pasteurella multocida (PM), Bovine coronavirus (BCV), bacterial mycoplasma, and aerobic culture results for the respiratory tract in cattle are covered.

For pigs, additional details encompass FarmType, age, weight-related information, and pathogen names such as Porcine Reproductive and Respiratory Syndrome (PRRS), Swine Infuenza(SI), and Mycoplasma hyopneumoniae are included. This enhanced representation facilitates a comprehensive understanding of pig health, covering aspects of farm classification, age or weight specifics, and the presence of specific pathogens.

Similarly, for poultry, LHO incorporates FarmType along with specific pathogen names like Infectious Bronchitis (IB), offering a detailed perspective on poultry health, including farm categorization and information on prevalent diseases.
